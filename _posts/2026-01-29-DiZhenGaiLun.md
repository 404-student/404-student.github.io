# 零、写在前面

如果你来看我的这个笔记，你大概率选上了地震概论。首先恭喜你选上了如此热门且优质的通识课，说明你的运气非常不错。当然我的运气也非常好，我一开始没打算选这门课的，因为把点数砸给另一门通识了。结果在第一周的周末，我没事干在刷新课程网，刚好多出了一个名额，于是我就意外选上了。所以选上这门课真是源于机缘巧合。

如果你尚且不了解地震概论，我来向你介绍一下。我是 25 秋的周五班，这门课之所以被大家推崇，不仅是因为给分好，更是因为其中对地震知识的深入讲解，以及适当且丰富的通识教育。这里作为笔记，无法向你传授通识教育的知识（其实我还真做了笔记，但是有些东西不好展示），我只能讲述如何拿到高分。考试题目源于课程，一旦遇到考点，教员会进行“反复强调——开始闲聊——再次强调”的丝滑连招，说明这是考点，只需记忆即可。因此该课程对文科生也极为友好，可以放心选。如果你没有认真听课，也最好不要去刷往年题，因为不同学期的不同课，强调的重点并不一致，建议过两遍回放，有用得多。

课程包括十个章节，pre，以及看电影，最后一节随堂考试。以防你不知道，有考试的通识课一般都是最后一周随堂考试。pre 和电影都是考试内容，pre 的题目会像前面的章节一样给出，所以不用担心要掌握 pre 的所有知识。电影虽然不会给出考题，但我调研了近三年的考题，全部都是同一道，在下文给出了。再次强调不同班的重点不一致，所以下面的知识，除了计算题与电影题，都不适用于你们，仅作为参考。

关于考勤，教员近期（指 25-26 寒假）反复在树洞出现并强调地概即将引入考勤，因此我就不好说了，以教员的规定为准。

关于 pre，组队人数建议为 4-8 人，大部分同学的形式是拿一张表，写三四百字的报告就行；可以报名进行课堂展示，一般只能有三到四个组参与，如果报名人数太多会进行抽签。课堂展示也可以水，但是我们班四个组都没水，都做了 PPT，并且自行构思了话题，没有抄袭往届的话题。你问我为什么知道，因为我也在卷（）pre 的给分方式是抽同学打分，当然这也只是形式，肯定会给满分的，做课堂展示的同学会多近两道选择题的 bonus。

关于考试，首先题型并非固定，但是**可以问**，这很重要，你不问就不告诉你，请在最后一节课的提问环节不要忘记这件事。常见的题型包括选择、判断、填空、简答、问答、论述、计算、画图等。并不是所有题型都一定出现，比如我所在的班就没有画图题。除了两道计算题和电影题是已经反复被使用的以外，其他所有题，不论题型，必然是上课时强调过的重点（不排除教员未来改变的情况）。讲下简答题、问答题和论述题的区别，简答题就是只要答到点上就行；问答题就得答全，而且一般点数较多；论述题不仅要答全，还要说一大堆废话。反正都肯定会在课上强调的，重点还是听课。

# 一、地震学的研究范围和历史

预计二十一世纪将有约 **1500 万人**死于地震。

近震和远震的分界线是 **1000 公里**。

# 二、地震波

P 波和 S 波的主要差异：

- **P 波的传播速度比 S 波快**，地震图上先出现 P 波；
- P 波和 S 波的质点振动（偏振）方向相互**垂直**；
- 一般情况下，三分量地震图上 P 波的**垂直**分量相对较强，S 波的水平分量相对较强。
- S 波的**低频**成分比 P 波丰富。
- 天然地震的震源破裂通常以剪切破裂和剪切错动为主，震源向外辐射的 S 波的**能量**比 P 波的强。
- P 波通过时，质元无转动运动，而有体积变化，是一种**无旋波**。S 波相反，是一种无散的**等容波**。

# 三、地震波的传播理论

首波的传播路径比直达波长，但深层介质的传播速度快，因此超过一定临界距离后，首波先到达。

*震中距的单位是度，1 度 = 110 km。

（注：前面标*表示非上课强调重点）

*费尔马原理：地震波在介质中传播的路径为走时最小的路径。推出斯涅尔定律：对于反射和折射：

$$\frac{\sin\theta_1}{v_1}=\frac{\sin\theta_2}{v_2}$$

走时曲线以震中距为横坐标，地震波到达时间为纵坐标，反映的是不同震中距对应的到达时间。

> $P_{41}T_{2}.$ 震源深度为 $10\text{ km}$，$\text{Pn}$ 波走时直线的斜率为 $0.125\text{ s/km}$，截距为 $3\sqrt{7}\text{ s}$，若均匀地壳内 $\text{P}$ 波速度已知为 $6\text{ km/s}$，试估计地幔顶部的 $\text{P}$ 波速度和地壳厚度。

**解：** 首先得知道运动轨迹：

```
------------------.----地面
  .              /
   \            /
    \          /
     \        /
------————————---------地幔
```

由于斜率为 $0.125\text{ s/km}$，地幔上的速度就是 $8\text{ km/s}$。又由于截距为 $3\sqrt{7}\text{ s}$，考虑极端情况就是在地幔上压根没跑，则 $s=vt=6·3\sqrt{7}=18\sqrt{7}\text{ km}$。但是它在地壳内是斜着跑的，临界角 $\sin i_c=v_1/v_2=0.75$，故

$$\frac{2H-10}{s}=\cos i_c$$

解得 $H=41\text{ km}$。

本题需要注意变体：如果震源深度为 $8\text{ km}$，则答案为 $40\text{ km}$。

# 四、地球内部的结构

**1522 年**，麦哲伦环球航行，证明地球是圆的。

*地壳下面并**不软**。

速度大小：$\text{Sg < Sn < Pg < Pn}$，横波必比纵波慢，其次是直达波比首波慢。题目会给出 $s-t$ 图，**因此速度越小的斜率越大。**

*研究大洋和大陆地壳的区别要用**面波**。

奥尔德姆在 1906 年先发现地核存在，古登堡只在 1914 年才发现，为什么地球液体核的界面叫**古登堡面**而非奥尔德姆面？

- 古登堡使用了**地震波反射震相**；
- 古登堡拥有更丰富的**地震记录**；
- 古登堡更精确估算了**核幔边界**的深度。

# 五、地震机制

*强烈地动的原因是**地表岩石的大规模迅速错动**。

断层的走向：沿着**断层上盘在右侧**的方向。该方向与正北的顺时针夹角为走向，范围为 0-360 度。

地震引起的振动源于破裂面。破裂起始的表面开始很小，很快扩展得非常大，但是扩展速率**不会超过岩石中 P 波的传播速度**。（选择题/判断题：破裂面的扩展速率（小于 P 波速度）。）

地震效率 = 地震波能量 / 地震能，范围为 **$7.5\sim15\%$**，小于 20%。

*沙滩球 beach ball：**正断层中间白两边黑，逆断层中间黑两边白，走滑断层是均匀的四象限**。（黑色是挤压，白色是拉伸）

*（？坏了我真没听懂）根据沙滩球判断断层：**正断层选陡面，逆断层选缓面，走滑断层看地震位置**。走滑断层是左旋。（原理：正断层与重力一起作用，因此断面陡；冲断层与重力相反，因此断面缓）

区分大彩虹和小彩虹的题：对于同一个有限断层，第一次均匀破裂，第二次加速破裂，那么第二次和第一次相比，断层的正前方有一个台站，这个台站接收到的地震波波幅会如何变化？**先变大再变小**。（加速了肯定会变大，但因为断层有限，最后必须变小，否则断层大小就不一样了）

板块之间**没有**清晰的板块边界。

# 六、地震仪及地震基本参数的测定

地震仪的出现具有**一百多年**的历史（1880-1890），它**标志**着地震学作为科学登上历史的舞台。

地震观测台网有很多分类方法，按照控制震级的大小来分，分为**微震台网和强震台网**。不要写成小地震台网和大地震台网！

震中定位的精度大约为 **10 千米**，震源深度的精度大约为 **20 千米**。

*里氏震级 $M_L$ 是使用伍德-安德森地震仪，测量出的最大地震波振幅，取以 10 为底的对数，单位为微米。对于 100 千米以外的地震，1 厘米的地震波为 4 级。

*$M_L,M_s,m_b$ 都属于里氏震级系统。

# 七、地震预报

简答题就简单答一答就好，**论述题**就要添油加醋地加一堆废话。比如之前的问题：

> 奥尔德姆先发现地核存在，为什么地球液体核的界面叫古登堡面而非奥尔德姆面？

如果是论述题，就不能按之前的答。总之是一定要添加很多内容，下面给出一个思路：

- 探测核幔边界时，信噪比最高的方法就是使用反射波，奥尔德姆却没有使用这种方法，而古登堡使用了**地震波反射震相**；
- 古登堡比奥尔德姆拥有更丰富的**地震记录**，而且考虑了地球实际的情况，而奥尔德姆却错误地认为射线路径是直线的；
- 古登堡更精确估算了**核幔边界**的深度，这一结论得到了实践的检验，后来用计算机计算出来的结果与其仅有几公里的误差。而奥尔德姆错误地认为地核半径在地球半径的 $2/5$ 左右，实际上应当大于一半。

为什么地震预报精度不高？

- 迄今地震学家仍未探索出一种确定性的**地震前兆**；
- 地震的观测是间接的，**各种因素**相互耦合并交织在一起，很难把它们分开。

# 八、宏观地震学

*震级相差 2 级，能量相差 1000 倍，能量单位是尔格（$10^{-7}J$）。

*全世界历年来，7 级地震加起来的能量比 8 级地震加起来小。

基本烈度相当于 **475 年**一遇的最大地震的烈度。

在宏观烈度大体相同的条件下，处于大地震远离震中的高耸建筑物的震害比中小级地震近震中距的情况**严重得多**。相反一样，处于大地震远离震中的**低矮**建筑物的震害比中小级地震近震中距的情况**轻得多**。

# 九、勘探地震学

地震勘探占地球物理勘探的 **97%**。

传统（天然）地震学利用**远场效应**，有如下优势：

- 震源可视为**点源**；
- 对**不同震相**可以分别研究。

同时有如下缺点：

- 丢失了大量**高频**信息。

而对于工程（勘探）地震学，我们恰恰需要高频信息。

*勘探地震学用**反射波**方法，信噪比高。

# 十、海啸

> 海啸传播：一个海啸如下图，从 $A$ 点开始向岸边 $D$ 靠近，长度如图所示。已知海啸波的速度 $v=\sqrt{gh}$，其中 $h$ 是海面深度，单位均为千米，$g=10m/s^2$，求海啸到达岸边的时间。

```
A-------B--------------C--------D
|  400  |      600     | 60 /---/
|       |             1|----
|4      |4      /------G
|       |/------
E-------F
```

**解：** 直接默写：

$$
\begin{align*}
v_A=v_{B}&=\sqrt{10\times4000}=200m/s\\
v_{C}&=\sqrt{10\times1000}=100m/s\\
v_D&=0\\
t_{AD}&=t_{AB}+t_{BC}+t_{CD}\\
t_{AB}&=\frac{s_{AB}}{v_{AB}}=2000s\\
t_{BC}&=\frac{s_{BC}}{\overline{v}_{BC}}=4000s\\
t_{CD}&=\frac{s_{CD}}{\overline{v}_{CD}}=1200s\\
t&=7200s=2h.
\end{align*}
$$

但是大家肯定要问，凭什么可以直接用两个速度的平均值来当做平均速度呢？学过高一物理的朋友们知道我们需要证明海啸遵循匀变速直线运动。求出加速度：

$$
a=\frac{dv}{dt}=\frac{dh}{dt}\sqrt{\frac{g}{h}}=v\sqrt{\frac{g}{h}}=g
$$

居然是定值，太好了。证毕。

*浅水波的定义：$\lambda>>h$，其中 $\lambda$ 为水波的波长，$h$ 为海平面深度。
